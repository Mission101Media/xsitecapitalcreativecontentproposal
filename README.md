# XSITE Capital Content Strategy

Interactive presentation prepared by Fredy Mfuko | Mission 101 Media.

## Deploy with Vercel

1. Upload this folder to a new GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Vercel will detect Next.js automatically. Keep the default build settings.
4. Select **Deploy**.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
